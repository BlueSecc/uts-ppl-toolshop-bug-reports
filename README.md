# UTS Praktikum PPL — Bug Reports (Toolshop)

Repositori ini menampung laporan bug hasil pengujian eksploratori pada AUT
ber-bug dibandingkan dengan oracle.

- **AUT (bug):** https://with-bugs.practicesoftwaretesting.com
- **Oracle (benar):** https://practicesoftwaretesting.com
- **Build:** Sprint 5
- **Tester:** Lalu Atnan Wiraguna

## Cara melaporkan
Gunakan template **Bug Report** saat membuat issue baru
(`.github/ISSUE_TEMPLATE/bug_report.md`).

## Konvensi label
- `type: bug` — jenis issue
- `severity: critical` | `severity: major` | `severity: minor` | `severity: trivial`
- `priority: P1` | `priority: P2` | `priority: P3`
- `area: cart` | `area: checkout` | `area: auth` | `area: payment`

## Konvensi evidence
Nama file gambar mengikuti pola `BUG-<id>_<judul-singkat>.png`.
